# Caresyntax

> Caresyntax is a surgical intelligence company that builds a vendor-neutral, enterprise-scale data platform for the operating room. Founded in 2013 in Berlin and dual-headquartered in Berlin and San Francisco, it captures video, audio, image, device, EMR, financial and outcomes data from inside and around the OR and applies AI analytics to it — pre-operative workflow optimization, real-time intraoperative decision support, and post-operative clinical safety, quality and utilization insights. Its PRIME365 layer handles vendor-neutral OR / medical-device integration; its qvident suite handles surgical performance management and analytics. Deployed in more than 4,000 operating rooms worldwide.

## API surface

Caresyntax publishes **no public API**. There is no developer portal, no API reference,
no OpenAPI/AsyncAPI/GraphQL contract, no SDKs, no CLI, no MCP server and no A2A agent
card. An API gateway is live at `https://api.caresyntax.com` (Kong 3.4.2) but every
probed path returns `404 {"message":"no Route matched with those values"}` — it carries
no publicly routed endpoint. Integration with the platform (EMR, PACS, scheduling
systems, OR devices) is delivered through enterprise and partner engagements rather
than a self-serve developer program.
